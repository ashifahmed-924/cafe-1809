# Yamato → Café 1809 adaptation

This homepage reuses the **structural rhythm** of a Yamato-inspired multi-section dining site (header → hero → modes → showcase → journey → signature story → interactive → menu → values → dining/order → gallery → gift → visit → footer) and retargets every section for a **Glen Waverley brunch café**.

## Mapping

| Yamato-style pattern | Café 1809 adaptation |
| --- | --- |
| Fusion / night dining hero | Morning brunch hero — “Brunch, made to linger.” |
| Experience modes (e.g. bar / omakase / table) | **Morning Brunch · Coffee Lounge · Shared Table · À La Carte** |
| Culinary journey (courses) | Day timeline: doors 7:30 → brunch table → lunch bowls/burgers → last orders |
| Table / grill signature story | **Brunch Signature Story** — pinned split reveal of **1809 Breaky** |
| Teppanyaki / interactive grill | Plate builder (base + add-ons + drink + pastry) — demo UI |
| Fine-dining menu chapters | Uber Eats menu discovery (6 categories × 3 dishes) + full list |
| Private dining / membership | Gift cards & membership dialogs (demo) + Uber Eats / DoorDash CTAs |
| Reservation | Hours, open status, demo reserve + real phone/email/maps |

## Visual language retained

- Alternating **ink / rice / porcelain** scenes
- Bodoni Moda + Manrope + sparse Noto Serif JP labels
- Clip-path **frame reveals** and scrubbed storytelling
- Persimmon / ultramarine / brass accents on midnight and rice grounds

## What changed for the café

- Copy, menu, hours, and CTAs are real Café 1809 data (`data/businessData.js`)
- Imagery is brunch / coffee stock (local WebP), not grill or night-club dining
- Delivery-first order path (Uber Eats) alongside in-person visit
- Daytime hours only (closes mid-afternoon)
